# Security policy

Report suspected vulnerabilities privately using **Security → Advisories →
Report a vulnerability** on GitHub. If private reporting is unavailable,
contact the maintainers through a private channel. Use public issues for
ordinary bugs and feature requests.

Include the affected version or commit, the operating system, the impact,
and the details needed to reproduce the issue. Remove credentials and
personal data from any attached logs or screenshots.

See [the security model](docs/security.md) for the app's trust boundaries
and how it stores credentials.
